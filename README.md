# Password-Cracking--JohnTheRipper-Networkwalks
🔐 Week 3 – Password Cracking using John the Ripper & Networkwalks
📌 Project Overview
As part of my Networkwalks Cybersecurity Internship – Week 3, I worked on a practical Password Cracking and Hash Analysis lab.

The objective of this project was to understand how password-protected files can be analyzed by extracting their password hashes and performing a controlled dictionary attack using John the Ripper. I also used the Networkwalks Password Cracker application to understand and demonstrate the same process through a web-based cybersecurity lab environment.

⚠️ Disclaimer: This project was performed in a controlled lab environment for educational and ethical cybersecurity purposes only.

🎯 Objectives
Understand password-protected PDF files and password hashes.
Extract a crackable hash from an encrypted PDF.
Understand the structure and purpose of password hashes.
Perform a dictionary-based password cracking attack using John the Ripper.
Verify the recovered password by unlocking the protected PDF.
Reproduce the password-cracking process using the Networkwalks Password Cracker application.
Capture and document the complete attack workflow.
